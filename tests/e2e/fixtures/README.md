# Legacy backup fixture

`legacy-v1-completed-demo.json` is an actual schema 1 backup exported by the 0.1.0 Android debug APK during the isolated emulator test on 2026-10-23. It contains synthetic demo learning records only: one completed quest, five attempts, and 80 XP. Its original session/reward structure is retained to test backward-compatible import rather than relabeling a new schema 2 export as schema 1.

`legacy-v4-partial-course-0.7.json` is an unmodified schema 4 download from the preserved, previously tested 0.7.0 production `dist`. On 2026-11-01, an isolated Chromium context completed six study cards and the first vocabulary question, then stopped at index 7 of the original 49-step advanced-300 lesson. It contains one first-correct attempt and 10 XP, with no `courseFlow` field. It tests resuming a real old in-progress course without replacing its stored steps. Capture evidence is in `artifacts/test-first/legacy-0.7-fixture-capture.json` and the adjacent 0.7.0 settings screenshot. The temporary preview server was stopped after capture.

`legacy-v5-native-0.8.json` wraps the actual 0.8.0 emulator six-table snapshot in a schema 5 backup envelope. The table records are unchanged: seven sessions, 101 attempts, four historical purchases, 998 earned / 580 spent / 418 available XP. It is not a file exported through the Android system picker. The source is `artifacts/android/test-first-2026-11-01T12-00-49-971Z/final-six-table-snapshot.json`.

`funded-v6-pricing-test.json` is a deliberately synthetic purchase-test fixture. `scripts/create-funded-pricing-fixture.ts` imports that baseline normally into learner storage and completes 309 additional ten-question review rounds through public DB answer/advance APIs at the fixed test clock `2026-11-02T03:00:00Z`. No XP or reward records are manually patched. The exported-and-reimported schema 6 result has 316 sessions, 3,191 attempts, the same four old receipts, and 30,662 earned / 580 spent / 30,082 available XP. Generation evidence is `artifacts/pricing/funded-fixture-generation.json`. These are automated test records, not a claim about a learner's study history.
