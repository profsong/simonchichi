# 시몬치치

사랑하는 우리 딸, 중학생 시몬치치를 위해 만든 앱니다. 영리를 목적으로 만든 앱도 아니고, 아이폰 안드로이드에서 내가 만든 앱을 올리기 불편해 일단 개인 사용 용도로 github에 올립니다. 혹시라도 이 앱을 다운로드 받으려는 분들은 다운로드 받지 않는 것을 추천합니다 ^^,,, 

한국어를 사용하는 중2 영어 상위권 학습자를 위한 로컬 우선 앱입니다. iPhone용 PWA와 Android APK를 제공하며, 학습 기록은 기기의 IndexedDB에 저장합니다. 로그인·광고·분석 추적기·결제·네트워크 AI 없이 실행합니다.

오늘 화면에서 **중등 심화 300** 또는 **수능 영어 2000**을 고르면 바로 학습할 수 있습니다. 사용자가 적재된 자료의 사용을 허용한 현재 정책을 반영했습니다. 원본의 초안 메타데이터는 보존하며, 외부 교사 검수 완료를 주장하지 않습니다.

## 실행

Node.js 22.12 이상과 npm을 준비합니다.

```powershell
npm install
npm run dev
```

기본 주소는 `http://localhost:4175`입니다. **오늘 → 학습 단어장 → 오늘 퀘스트 시작**으로 진행합니다. 별도의 콘텐츠 허용 설정은 없습니다.

```powershell
npm run build
npm run preview
```

일반 빌드의 `dist/`에 앱과 두 과정이 포함됩니다. `build:demo`는 기존 저장소 호환성을 확인하는 개발 용도로 남아 있지만 현재 학습 기능을 쓰는 데 필요하지 않습니다. 일반 빌드는 `?demo=1`을 무시합니다. 내부 저장소 구분은 화면에 노출하지 않으며 이전 백업은 원래 모드로 검증한 뒤 현재 저장소로 복원할 수 있습니다.

## GitHub Pages

GitHub Pages용 [배포 워크플로](.github/workflows/deploy-pages.yml)와 프로젝트 경로 지원을 준비했습니다. 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택하면 `main`의 검사·빌드가 통과한 뒤 `dist/`만 배포합니다. 계정 사이트 `/`와 프로젝트 사이트 `/저장소명/`의 경로를 자동으로 맞춥니다.

아직 실제 GitHub 배포 완료를 확인한 것은 아닙니다. Pages는 기본적으로 공개 웹사이트이며 앱의 학습 자료·그림도 내려받을 수 있습니다. 개인 백업·원본 PDF·APK는 업로드에서 제외하고, 기존 기기의 학습 기록은 JSON 백업으로 옮깁니다. 첫 설정·공개 범위·iPhone 설치·실제 로컬 검사 결과는 [GitHub Pages 안내](docs/GITHUB_PAGES.md)를 확인하세요.

다음 진행에는 `profsong/simonchichi` 공개 저장소를 README 포함으로 만들고 연결 앱의 접근과 Pages의 GitHub Actions 게시를 허용해야 합니다. 전달용 소스·정적 ZIP의 이름과 용도도 위 안내에 정리했습니다.

## 학습 구성

| 단어장         |               전체 단어 |  회차 |  지도 묶음 |
| -------------- | ----------------------: | ----: | ---------: |
| 중등 심화 300  |   기존 B1·B2·B3의 300개 |  15회 |  5회씩 3개 |
| 수능 영어 2000 | PDF 원문 순서의 2,000개 | 100회 | 5회씩 20개 |

- **기억 채우기 5개 → 단어 테스트 20개 → 문장 해독 2개 → 독해 미션 2개 → 첫 단어 오답 재시험**로 진행합니다. 처음에는 기억 채우기를 5개 미리보기 카드로 시작합니다.
- 단어는 별도 뜻 카드 없이 영어→한국어 뜻 고르기로 바로 시작합니다. 기본 29단계·첫 회차 24문항이며, 처음 틀린 단어만 독해 뒤 한 번 다시 풀어 전체 29~49단계가 됩니다. 12분 안에 끝난다고 약속하지 않으며 중간에 저장하고 나갈 수 있습니다.
- 같은 날 다음 회차는 선택 사항입니다. 완료 보너스는 오답 재시험까지 마친 뒤 날짜당 한 번이고 중복 탭·새로고침으로 보상이 늘지 않습니다.
- 두 책의 진도는 독립적입니다. 겹치는 176단어는 수능 과정에서 빠지지 않으며 공통 어휘의 SRS 기록은 공유합니다. 이전 60단계의 완료 기록은 새 15/100회차로 자동 환산하지 않습니다.
- **복습함**은 정사각형 아바타 방, 별도 10단어 테스트, 단어장 링크 순서로 제공합니다. 배운 단어 중 5개는 객관식, 5개는 첫 글자를 보고 영어로 입력합니다. 이전 오답의 추출 확률을 높이며 힌트 회상은 독립 회상 숙련과 구별합니다.
- 검색용 단어장은 영어·한글 뜻·원문 DAY·사전 출처를 제공합니다. 중복 제외 목록의 수능 신규 단어는 1,824개지만 학습 과정은 전체 2,000개입니다. 단순 조회는 XP·진도를 바꾸지 않습니다.
- 몬치치·시치와레·시폼푸린의 방을 배경·옷·액세서리로 꾸밉니다. 아이템은 학습 XP로 구매하고 소유품은 무료로 다시 장착합니다. 상단 잔액과 성장 기록의 누적 획득 XP를 구분합니다.
- 유료 배경은 12,000 XP, 일반 옷은 6,000 XP, 액세서리는 2,500 XP입니다. 새 프리미엄 옷인 나이키 후드티·아디다스 패딩·버버리 코트는 각각 7,000 XP입니다. 배경·일반 옷·액세서리는 하루 새 탐험 3~4회의 기준 수입으로 약 14/7/3일을 목표로 하며 실제 기간은 정답률과 복습에 따라 달라집니다. 기존 구매 금액·소유권·잔액은 보존합니다.
- 액세서리는 민트 리본·하트 선글라스 등 새 10종을 더해 무료 미착용 포함 14종입니다. 구매 전 미리보기를 제공하며 세 친구 모두 같은 소유품을 사용합니다. 옷도 새 10종을 더해 무료 원래 옷 포함 14종이며, 전체 상품은 42개(무료 3·유료 39)입니다.
- 배경은 14종입니다. 미구매 배경에는 이름·설명·가격만 보이고, 구매하면 그림이 나타납니다. 보유 배경은 장착 여부와 관계없이 미리보기를 유지하며 옷·액세서리는 구매 전에도 볼 수 있습니다.
- 새 복습 테스트는 완료 시 오늘 기본 회차 최대 XP의 30%를 첫 응답 정답 수에 비례해 지급합니다. 정상적인 새 테스트는 같은 날에도 다시 받을 수 있고 같은 테스트의 중복 완료는 보상을 늘리지 않습니다.
- 화면 테마, 선택형 기기 음성, JSON 백업·복원을 제공합니다. 읽기 단계 수동 선택은 없습니다.

회차별 실제 20단어는 [현재 과정 단어표](docs/COURSE_GUIDE.md)에서 확인합니다. 자세한 사용법은 [사용 안내](docs/USER_GUIDE.md), 현재 요구사항은 [제품 명세](docs/PRODUCT_SPEC.md), 이전 설계와 달라진 이유는 [결정 기록](docs/DECISIONS.md)을 확인하세요. 진단·주간 보스전·적응형 난도·보호자 화면은 후속 범위입니다. 공인 영어 등급이나 수능 점수를 예측하지 않습니다.

## Android 설치

[시몬치치 0.11.0 APK](artifacts/android/simonchichi-0.11.0.apk)는 개인 사용을 위한 디버그 서명 파일입니다. 한 번 설치하면 PC 서버 없이 오프라인으로 실행합니다. 이전 사용자는 먼저 백업한 뒤 **기존 앱을 삭제하지 않고 새 APK를 설치**합니다.

```powershell
# 같은 Wi-Fi의 휴대폰에 APK를 전달
npm run android:serve
# Java 21·Android SDK 36을 갖춘 PC에서 재생성
npm run android:build
```

설치 페이지의 4180 포트 주소를 휴대폰에서 열어 내려받습니다. 설치 후 전달 서버는 종료해도 됩니다. [Android 설치 안내](docs/ANDROID_INSTALL.md)에 환경과 기록 보관 방법을 정리했습니다. 실제 변경·검사·APK 정보는 [0.11.0 옷 확장 보고서](docs/OUTFIT_EXPANSION_REPORT.md)를 확인하세요.

## 검사

```powershell
npm run validate:content
npm run typecheck
npm run lint
npm run test
npm run build
npx playwright install chromium webkit
npm run test:e2e
npm run test:e2e:production
```

두 E2E 명령은 일반 빌드를 만들고 각각 4173·4174 포트를 사용하므로 순서대로 실행합니다. Chromium/WebKit에서 새 29단계/오답 재시험·기존 49단계 재개·단어장 전환·복습 테스트·중복 보상 방지·방 꾸미기 구매/장착·잔액·백업·오프라인을 확인합니다. Playwright WebKit은 실제 iPhone Safari/홈 화면 검증을 대신하지 않습니다. 실제 Android 휴대폰과 iPhone 검증 여부는 [보고서](docs/OUTFIT_EXPANSION_REPORT.md)에 자동 검사와 구분하여 기록합니다.

최종 단위 186개, 웹 26개 시나리오(주 24+배포 2), Android 에뮬레이터 4개 검사가 통과했습니다. 실제 명령·결과와 APK 정보는 [옷 확장 보고서](docs/OUTFIT_EXPANSION_REPORT.md)에 기록합니다. 이전 액세서리 결과는 [0.10.0 보고서](docs/ACCESSORY_EXPANSION_REPORT.md), 기본 가격 정책은 [0.9.0 보고서](docs/PRICE_BALANCE_REPORT.md)에 보존했습니다. 실제 Android 휴대폰과 iPhone은 미검증입니다.

원본 자료·사전 보강·현재 과정의 독립 검사는 다음 명령을 사용합니다.

```powershell
python tools/validate_content_bank.py
npm run validate:wordbooks
python tools/build_wordbook_courses.py --check
npm run validate:courses
```

구조 검사는 교육적 난도와 모든 의미상의 정답 유일성을 보장하지 않습니다. 콘텐츠의 재생성은 검토한 원본 수정 이후에 실행합니다.

## iPhone 실행·검증

1. 화면만 확인하려면 같은 Wi-Fi에서 `npm run dev`의 Network 주소를 Safari로 엽니다.
2. 설치·오프라인 시험은 `npm run build`의 `dist/`를 접근 가능한 **HTTPS 정적 호스팅**에 올립니다. 이 작업에서 외부 배포를 자동 실행하지는 않습니다.
3. Safari 공유 → **홈 화면에 추가**를 선택합니다. 온라인으로 한 번 열고 설정에서 오프라인 준비를 확인합니다.
4. 두 단어장을 바꾸어 학습·중단·재개하고, 복습 10문항과 입력 키보드, 비행기 모드 실행, 백업 → 초기화 → 복원을 확인합니다.
5. [실제 iPhone 체크리스트](docs/IPHONE_TEST_CHECKLIST.md)에 기기와 iOS 버전·실제 결과를 기록합니다. **현재 실제 iPhone 검증은 미실시입니다.**

PC 사설 IP의 일반 HTTP 접속은 service worker/오프라인 설치 검증 경로가 아닙니다.

## 데이터와 확장

| 경로                                                              | 역할                                               |
| ----------------------------------------------------------------- | -------------------------------------------------- |
| `src/app`, `src/components`, `src/features`                       | 화면·접근성·탐색                                   |
| `src/core`, `src/data/db.ts`                                      | 채점·SRS·선택·보상·저장·백업                       |
| `src/data/courses/`                                               | 새 15/100회차와 20단어·구문·독해                   |
| `content_src/courses/`, `tools/build_wordbook_courses.py`         | 검토 가능한 원작 PSV와 결정적 과정 생성            |
| `src/data/seed-content.json`                                      | 기존 300어휘/60계획 문제은행 원본과 안정적 ID 보존 |
| `content_src/wordbooks/`, `src/data/wordbooks/`                   | 원문·뜻 출처·중복 연결·동기화 자료                 |
| `src/platform`, `android`                                         | 네이티브 런타임과 시스템 백업 저장창               |
| `scripts/build-android.mjs`, `scripts/serve-android-download.mjs` | APK 생성과 LAN 전달                                |
| `tests/unit`, `tests/e2e`, `scripts/test-android*.mjs`            | 단위·브라우저·Android 검사                         |

PDF의 빈 뜻 칸과 원문 표기는 그대로 보존하고 별도 공개 사전 보강 자료에 한국어 뜻을 기록했습니다. 자세한 출처는 [뜻 보강 보고서](docs/WORDBOOK_MEANINGS_REPORT.md), 신규 JSON 단어장 검증과 중복 규칙은 [가져오기 보고서](docs/WORDBOOK_IMPORT_REPORT.md)를 참고하세요. 새 단어장 목록을 추가하는 일과 학습 회차·문항을 저작하는 일은 별도입니다. 오프라인 설치 앱에는 다시 빌드한 새 APK/PWA 업데이트가 필요하며 PC 원본 폴더를 실시간으로 읽지 않습니다.

기록은 자동으로 다른 기기에 동기화되지 않습니다. 앱 삭제·브라우저 데이터 삭제 전에 JSON 백업을 개인 파일로 보관하세요.
