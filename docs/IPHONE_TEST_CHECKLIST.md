## 준비

1. PC에서 `npm install`과 `npm run build`를 실행하고 `dist/`를 접근 가능한 HTTPS 정적 호스팅에 올립니다. 일반 빌드의 두 단어장을 그대로 사용합니다.
2. iPhone Safari에서 주소를 열고 공유 → **홈 화면에 추가**로 설치합니다. 홈 화면 아이콘으로 앱을 실행합니다.
3. 설정에서 오프라인 준비를 확인합니다. 기존 기록이 있으면 초기화 전에 JSON 백업을 파일 앱에 저장합니다.

화면만 빠르게 확인할 때는 같은 Wi-Fi에서 `npm run dev`의 Network 주소로 접속할 수 있습니다. PC의 사설 IP에 대한 HTTP 접속은 PWA 오프라인 시험의 대체 경로가 아닙니다.

## 콘텐츠와 전체 퀘스트

- [ ] 별도 콘텐츠 허용 설정 없이 오늘 퀘스트를 시작할 수 있다. 준비 안내·데모 토글·읽기 밴드 선택이 없다.
- [ ] 오늘 상단과 설정에서 학습 단어장을 바꾸고, 새 실행에도 선택이 유지된다.
- [ ] 기억 채우기 5개 → 단어 뜻 고르기 20개 → 구문 2 → 독해 2지문/2문항 → 완료까지 진행된다.
- [ ] 처음의 기억 채우기는 5개 미리보기이며, 배운 단어가 있으면 복습 문제를 제공한다.
- [ ] 기본 29단계와 마지막 오답 재시험을 한 번에 하지 않고 저장·재개할 수 있으며 12분 내 완료를 강요하지 않는다.
- [ ] 선택지를 바꿀 수 있고, 정답 확인 후 해설과 정답이 명확히 보인다.
- [ ] 독해 근거가 제출 전에 정답 힌트로 노출되지 않고, 제출 후에는 본문의 실제 문구와 일치한다.
- [ ] 답을 빠르게 여러 번 탭해도 답변과 XP가 중복 증가하지 않는다.
- [ ] 정답 확인 직후 앱을 닫고 다시 열어도 결과가 유지되고 XP가 늘어나지 않는다.
- [ ] 퀘스트 중간에 홈으로 나갔다가 이어서 시작하면 같은 문항에서 계속된다.
- [ ] 완료 후 다시 열어도 완료 상태와 하루 완료 보상이 유지된다.
- [ ] 제한시간·출석 감점·공인 영어 등급 또는 수능 성적 예측 문구가 없다.

## 화면·접근성

- [ ] 작은 화면 세로 방향에서 가로 스크롤이나 잘린 정답 버튼이 없다.
- [ ] 큰 화면, 가로 방향, 디스플레이 확대에서도 읽을 수 있다.
- [ ] 노치와 하단 홈 제스처 영역에 탐색 버튼이 가려지지 않는다.
- [ ] 영어 입력 시 키보드가 답 입력·제출 버튼을 가리지 않는다.
- [ ] Safari 글자 크기를 확대해도 지문·선택지·버튼이 겹치지 않는다.
- [ ] VoiceOver로 탐색 탭, 문항, 선택지, 입력란, 정답 피드백을 읽고 조작할 수 있다.
- [ ] 포커스가 보이고 선택 상태·정답·오답이 색상 외 텍스트로 구분된다.
- [ ] 자주 사용하는 터치 대상이 손가락으로 누르기 충분히 크다(기본 44 CSS px).
- [ ] iOS 동작 줄이기 설정에서 불필요한 움직임이 줄어든다.

## 오프라인과 다음날 복습

- [ ] 온라인으로 앱과 콘텐츠를 한 번 열고 서비스 워커 준비 후 앱을 종료한다.
- [ ] 비행기 모드로 전환하고 Wi-Fi도 끈 상태에서 홈 화면 아이콘으로 앱이 열린다.
- [ ] 오프라인에서 적재된 문제·지문·해설이 표시되고 퀘스트를 완료할 수 있다.
- [ ] 오프라인에서 앱을 다시 열어도 완료 기록과 XP가 유지된다.
- [ ] 선택한 책에서 배운 단어 10개 이상일 때 복습 테스트가 활성화된다.
- [ ] 객관식 5개·첫 글자 입력 5개로 서로 다른 10단어를 풀고, 재개해도 추출 단어가 유지된다.
- [ ] 첫 글자 입력 정답이 무힌트 회상 숙련으로 집계되지 않는다.
- [ ] 다음날 실제 로컬 날짜의 복습 예약과 기억 채우기가 맞다. 날짜를 시뮬레이션했다면 방법을 기록한다.
- [ ] 잘못된 답과 힌트 사용 뒤 복습 예약이 생기며 숙련 완료로 표시하지 않는다.
- [ ] 쉬는 날 이후 돌아와도 감점이나 학습 실패 경고가 없다.

## 사이트 게시 중단·재게시 조건 확인

현재 **미실시**입니다. 이 체크리스트는 실제 GitHub 저장소 공개 범위나 게시 상태를 임의로 변경하라는 지시가 아닙니다. 별도 허용된 시험용 호스팅에서 정상 응답과 404를 전환해 확인하고, 실제 GitHub 전환을 시험했다면 요금제·설정·배포 결과를 따로 기록합니다.

- [ ] Safari 탭과 홈 화면 앱을 구분해 온라인 최초 설치·오프라인 준비·종료 후 재실행을 확인한다.
- [ ] 학습 중 위치·XP·구매/장착 상태의 기준값을 기록하고 JSON 백업을 파일 앱에 보관한다.
- [ ] 정상 캐시가 있는 상태에서 인터넷 연결은 유지하되 서버가 404를 반환하도록 한 뒤 홈 화면 앱을 다시 열어 기존 화면·자료가 보이는지 확인한다.
- [ ] 위 상태에서 문항을 풀고 앱을 종료·재실행해 답변·XP가 한 번만 저장되는지 확인한다.
- [ ] `sw.js` 업데이트 요청 실패가 기존 저장소 삭제나 사용 불가능 안내로 잘못 이어지지 않는지 확인한다.
- [ ] 서버가 다시 정상 게시된 뒤 새 버전의 업데이트 안내·적용·활성화와 기존 기록 일치를 확인한다.
- [ ] 업데이트 직후 다시 비행기 모드로 열어 자료·라이선스·방 꾸미기가 작동하는지 확인한다.
- [ ] 새로 연 브라우저/다른 기기에는 이전 캐시나 학습 기록이 자동으로 생기지 않으며 백업 복원이 필요함을 확인한다.
- [ ] 웹사이트 데이터 삭제 시험이 필요하면 복구 가능한 별도 시험 기록만 사용하고, JSON 복원 결과를 확인한다. 실제 학습 기록으로 무백업 삭제 시험을 하지 않는다.

위 결과는 해당 기기·iOS 버전에서의 관찰이며 영구 저장 보장이 아닙니다. 서버의 404, 기기의 네트워크 단절, Cache/IndexedDB 정리, 새 service worker 활성화를 서로 구분해 기록합니다. 정책 근거는 [GitHub Pages 안내](GITHUB_PAGES.md)를 참고합니다.

## 문제 중심 단어 학습과 마지막 재시험

- [ ] 기억 채우기 뒤 20단어가 별도 뜻 카드 없이 영어→한국어 뜻 고르기로 시작한다.
- [ ] 독해 뒤 처음 틀린 단어만 원래 순서로 한 번 다시 나오며 모두 맞히면 곧바로 완료된다.
- [ ] 기억 채우기·구문·독해 오답은 재시험에 섞이지 않고 재시험 오답도 반복하지 않는다.
- [ ] 재시험 중 앱을 닫거나 백업/복원해도 같은 위치와 답변으로 돌아온다.
- [ ] 재시험 정답은 3 XP만 한 번 받고 완료 보너스는 재시험 종료 뒤 한 번만 생긴다.
- [ ] 완료 화면에 이번 탐험 단어 20개가 보인다.
- [ ] 이전 49단계 진행 중 백업을 복원하면 원래 뜻 카드와 위치로 이어진다.

## 오답노트와 전용 퀴즈

- [ ] 오늘의 ‘오답 다시 도전’이 실제 버튼으로 작동하며 오답이 없어도 빈 노트를 연다.
- [ ] 단어·문장·독해에서 틀린 답을 저장한 직후 회차를 끝내지 않아도 노트에 나타난다.
- [ ] 복습함의 오답노트 진입, 영역 필터·검색·정답과 근거 펼치기를 VoiceOver와 작은 화면에서 조작한다.
- [ ] 다른 단어장을 선택해도 전역 오답 목록이 유지되고 두 책의 같은 canonical 단어가 중복되지 않는다.
- [ ] 정답 한 번은 ‘1 / 2회’로 남고 다른 퀴즈에서 다시 맞히면 해제된다. 같은 세션 중복 탭·재실행은 두 번으로 세지 않는다.
- [ ] 다시 틀리면 횟수가 0으로 돌아가며 해제했던 항목도 새 오답 뒤 다시 나타난다.
- [ ] 기존 회차 재시험 정답은 한 번 기여하고, 이미 확정한 회차 재시험은 오답노트에서 해제돼도 원래 문항을 유지한다.
- [ ] 전용 퀴즈는 오답이 1개여도 시작하며 최대 10개로 구성되고 추가 XP·일일 보너스·과정 완료를 만들지 않는다.
- [ ] 전용 퀴즈에 즉시 재도전이 없고 저장·새로고침·백업/복원·비행기 모드에도 문항·위치·해제 횟수가 유지된다.
- [ ] 같은 HTTPS origin의 기존 홈 화면 아이콘에서 앱을 업데이트한 뒤 답변·XP·진도·구매·장착과 백업 내용이 보존된다. 업데이트를 위해 앱이나 웹사이트 데이터를 지우지 않는다.

이 항목도 현재 **실제 iPhone 미실시**입니다. 기존 기록이 있는 기기는 먼저 JSON 백업을 보관하며, 다른 origin으로의 이전과 같은 origin에서의 업데이트를 구별합니다.

## 단어장과 모험 지도

- [ ] 중등 심화 300은 15회, 수능 영어 2000은 100회이며, 책을 바꿔도 각각의 완료·진행 위치가 유지된다.
- [ ] 이전 60단계 기록은 이전 탐험으로 남고 새 15/100회차를 자동 완료하지 않는다.
- [ ] 수능 단어장에서 `provide`·`제공하다`를 검색하고 뜻 출처·이용 조건을 읽을 수 있다.
- [ ] 원문 DAY와 중복 제외를 조작하고, VoiceOver로 검색 결과·뜻 출처를 확인할 수 있다.
- [ ] 사전 목록을 한 번 연 뒤 비행기 모드에서도 뜻이 보이고 탐색 전후 XP·진도가 같다.
- [ ] 원문 표기 확인·용법 주의 안내가 잘리거나 가로로 넘치지 않는다.

## 아바타 방·구매·복습 보상

- [ ] 복습함에서 정사각형 방 → 복습 테스트 → 단어장 링크 순서로 보인다.
- [ ] 작은 화면·가로 방향·VoiceOver에서 배경/옷/액세서리 선택과 상품 가격을 확인할 수 있다.
- [ ] 유료 배경 12,000 XP·일반 옷 6,000 XP·프리미엄 3종 옷 7,000 XP·액세서리 2,500 XP와 부족한 잔액 안내가 잘리지 않는다.
- [ ] 액세서리 14종(무료 미착용 포함)이 보이며 새 10종은 구매 전에도 미리보기가 있다.
- [ ] 옷 14종과 새 10종의 구매 전 미리보기, 일반 6,000 XP/지정 프리미엄 7,000 XP를 확인한다.
- [ ] 새 옷을 세 친구에 장착했을 때 얼굴·팔·다리·액세서리와 겹침이 자연스럽고 작은 미리보기가 잘리지 않는다.
- [ ] 일반/프리미엄 옷 구매·중복 탭·무료 재장착 뒤 실제 가격만 한 번 차감되며 백업·오프라인 재실행에도 유지된다.
- [ ] 새 액세서리를 몬치치·시치와레·시폼푸린에 장착했을 때 얼굴·귀가 불필요하게 가려지거나 프로필에서 장식이 잘리지 않는다.
- [ ] 신규 액세서리 구매·친구 변경·백업 복원·오프라인 재실행 뒤 소유품과 장착이 유지된다.
- [ ] 이전 구매가 있는 업데이트에서 소유품·예전 지출·잔액이 그대로이고 재장착은 무료다.
- [ ] 새 가격 구매를 중복 탭해도 한 번만 차감되며 백업 6 복원 뒤 과거/신규 영수증과 잔액이 같다.
- [ ] 배경 14종 목록에서 미구매 배경은 이름·설명·가격만 보이며 그림·이미지 빈자리가 없다.
- [ ] 새 배경 구매 후 그림이 나타나고, 이전에 산 비장착 배경도 미리보기가 남는다.
- [ ] 긴 배경 목록을 VoiceOver와 작은 화면에서 탐색하고 구매 버튼으로 초점을 옮길 수 있다.
- [ ] 잔액 부족 상태에서는 구매되지 않고, 빠른 중복 탭도 한 번만 차감한다.
- [ ] 소유품 재장착·무료 기본 복귀 시 잔액이 줄지 않는다.
- [ ] 구매 후 상단 잔액은 줄지만 성장 기록의 누적 XP와 학습 기록은 같다.
- [ ] 친구를 바꾸거나 오프라인으로 다시 열어도 구매·장착 상태가 유지된다.
- [ ] 새 복습 완료 시 첫 정답 비율대로 한 번 보상하고 새 테스트는 같은 날에도 보상한다.
- [ ] 같은 테스트를 재실행·중복 완료해도 보상이 늘지 않는다.
