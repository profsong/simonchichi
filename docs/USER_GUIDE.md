# 시몬치치 사용 안내

오늘 화면에서 단어장을 고르고 바로 시작합니다. 제한시간이나 쉬는 날의 감점은 없습니다. 한 번에 끝내기 어려우면 저장하고 나갔다가 이어 할 수 있습니다.

## 단어장 선택과 지도

**오늘 상단 또는 설정 → 학습 단어장**에서 고릅니다.

| 단어장         | 학습 분량             | 지도           |
| -------------- | --------------------- | -------------- |
| 중등 심화 300  | 기존 300단어          | 20단어씩 15회  |
| 수능 영어 2000 | 원문 순서의 2,000단어 | 20단어씩 100회 |

[현재 과정 단어표](COURSE_GUIDE.md)에서 각 회차의 20단어를 미리 확인할 수 있습니다. 선택은 앱을 닫아도 유지됩니다. 단어장을 바꾸면 오늘의 회차와 모험 지도도 바뀝니다. 각각 진행하던 위치와 완료 기록을 따로 보관하므로 두 단어장을 오가며 공부할 수 있습니다. 공통인 176단어의 기억 기록은 함께 사용하되 수능 과정에서도 그 단어들을 빠뜨리지 않습니다.

기존 버전의 12챕터·60단계 기록은 성장 기록의 **이전 탐험**으로 남습니다. 과거 완료가 새 20단어 회차를 자동 완료시키지는 않습니다.

## 한 회차 진행하기

1. **오늘 퀘스트 시작**을 누릅니다.
2. **기억 채우기 5단어**: 배운 단어를 다시 만납니다. 배운 단어가 5개보다 적으면 부족한 수만큼 이번 회차 단어를 미리 봅니다.
3. **단어 테스트 20단어**: 영어 단어를 보고 한국어 뜻 네 개 중 하나를 고릅니다. 별도 뜻 카드 없이 문제부터 시작합니다.
4. **문장 해독 2개**와 **독해 미션 2개**를 풉니다. 독해 제출 뒤 지문 속 실제 근거와 한국어 설명을 확인합니다.
5. **오답 다시 도전**: 독해 뒤 처음 틀린 단어만 원래 순서로 한 번 다시 풉니다. 모두 맞혔다면 이 단계 없이 완료됩니다.
6. 완료 뒤 **오늘의 탐험 마치기**로 쉬거나 **다음 퀘스트 시작**으로 이어 갑니다.

기본은 29단계입니다. 처음에는 기억 채우기 미리보기 카드 5개와 답변 문제 24개가 있습니다. 배운 단어로 기억 채우기를 할 때는 기본 답변 문제가 최대 29개가 됩니다. 첫 단어 오답 0~20개가 마지막에 더해져 전체는 29~49단계입니다. 기억 채우기·구문·독해 오답은 마지막 단어 재시험에 들어가지 않습니다. 12분 안에 끝낸다는 약속이나 시간 제한은 없습니다.

중간에는 **저장하고 나가기**, 다시 할 때는 **탐험 이어하기**를 누릅니다. 정답 확인 직후 앱을 닫아도 제출한 답변과 해설은 남습니다. 빠른 중복 탭이나 새로고침으로 XP가 늘어나지 않습니다.

새 단어 테스트에서는 틀린 직후 바로 재도전하지 않습니다. 마지막 재시험도 한 번만 풀고, 다시 틀리면 해설을 확인한 뒤 마칩니다. 재시험 정답은 기존 재도전 보상 3 XP를 한 번 받을 수 있으며 새 첫 정답 10 XP를 만들지 않습니다.

날짜당 첫 회차 완료 보너스는 30 XP이며 마지막 오답 재시험까지 마친 뒤 지급합니다. 첫 회차 24문항을 모두 첫 응답에 맞히면 270 XP이며 실제 XP는 정답 여부와 재도전에 따라 달라집니다. 이미 보상한 문항은 다시 풀어도 첫 정답 보상을 중복 지급하지 않습니다.

## 나의 아바타 방

복습함 맨 위의 정사각형 방에 설정에서 고른 친구가 나타납니다. 방 꾸미기에서 **배경·옷·액세서리**를 고릅니다. 각 상품의 XP 가격을 확인하고 구매하면 바로 장착됩니다. 무료 기본 아이템으로 돌아가거나 소유한 아이템을 다시 장착할 때는 XP를 쓰지 않습니다. 친구를 바꾸어도 소유품과 장착 선택은 유지됩니다.

배경은 14종입니다. 아직 사지 않은 배경은 이름·설명·가격만 보이며 **구매하면 그림이 나타납니다**. 무료 민트 공부방과 이미 산 배경은 미리보기를 볼 수 있고, 다른 배경을 장착해도 소유품 그림은 남습니다. 옷·액세서리는 구매 전에도 그림을 확인할 수 있습니다.

유료 배경은 **12,000 XP**, 일반 옷은 **6,000 XP**, 액세서리는 **2,500 XP**입니다. 새 프리미엄 옷인 **나이키 후드티·아디다스 패딩·버버리 코트**는 각각 **7,000 XP**입니다. 하루 새 탐험 3~4회에서 새 문제를 모두 처음에 맞히는 기준으로 배경 약 14일, 일반 옷 약 7일, 액세서리 약 3일을 목표로 정한 가격입니다. 실제 기간은 정답률과 별도 복습에 따라 달라지며 정해진 날까지 기다리는 잠금은 없습니다.

0.8.0 이전에 산 아이템은 그대로 소유하며 **예전 결제 금액과 잔액을 유지**합니다. 인상분을 다시 내지 않습니다. 새 가격은 앞으로 처음 구매하는 아이템에만 적용합니다.

옷도 무료 ‘원래 옷’을 포함해 14종입니다. 새 일반 옷 **민트 가디건·데님 재킷·스트라이프 니트·라벤더 맨투맨·레몬 레인코트·크림 플리스·리본 원피스**와 위 프리미엄 3종을 더했습니다. 세 친구 모두 입을 수 있고 한 번에 한 벌을 장착합니다. 원래 옷으로 돌아가거나 이미 산 옷을 바꿔 입을 때는 추가로 결제하지 않습니다.

액세서리는 ‘액세서리 없이’를 포함해 14종입니다. 새로 추가된 **민트 리본·별빛 머리핀·달빛 머리핀·나비 머리핀·데이지 핀·진주 머리띠·하트 선글라스·민트 스카프·행운의 클로버·하늘 베레모**도 각각 2,500 XP입니다. 세 친구 모두 사용할 수 있고 한 번에 하나만 장착합니다. 구매 전 미리보기로 모습을 확인하고, 친구를 바꾼 뒤에도 같은 소유품을 사용할 수 있습니다.

상단 XP는 **사용 가능한 잔액**입니다. 구매한 만큼 줄어들지만 성장 기록의 **누적 획득 XP**, 정답·복습·완료 기록은 줄지 않습니다. 잔액이 부족하면 더 학습한 뒤 선택할 수 있습니다. 실제 돈 결제는 없습니다.

## 10단어 복습 테스트

**복습함 → 10단어 복습 테스트 시작**을 누릅니다. 선택한 단어장에서 배운 단어가 10개 이상일 때 시작할 수 있습니다.

서로 다른 10단어 중 5개는 뜻 고르기, 5개는 첫 글자를 보고 영어로 쓰기입니다. 최근 틀린 단어가 더 자주 뽑히고 잘 맞힌 단어도 가끔 등장합니다. 첫 글자가 이미 보인 쓰기 정답은 도움 없는 회상으로 계산하지 않습니다.

중간에 나갔다면 **복습 테스트 이어하기**로 같은 10개를 마저 풉니다. 새로 열 때마다 단어를 다시 뽑지 않습니다. 복습 완료는 새 과정 회차를 완료시키거나 하루 완료 보너스를 추가하지 않습니다. 대신 새 복습 테스트에는 별도 XP 보상이 있습니다.

테스트를 시작할 때 오늘 선택한 단어장의 기본 회차 보상을 기준으로 최대 XP를 정합니다. 기본 회차 최대가 320 XP이면 복습 최대는 96 XP, 첫 미리보기 회차 270 XP이면 81 XP입니다. 실제 지급량은 **최대 보상 × 첫 응답 정답 수 ÷ 10**이며 소수점은 버립니다. 최대 96 XP에서 5개를 처음에 맞히면 48 XP입니다. 오답을 재도전해 맞혀도 첫 정답 수에는 더하지 않습니다.

10문항을 모두 마칠 때 한 번 지급합니다. 새 테스트를 시작하면 같은 날에도 다시 받을 수 있습니다. 같은 테스트의 중복 제출·완료·새로고침으로는 더 받지 않습니다. 이전 버전에서 이미 시작한 복습은 원래 보상 기록을 유지합니다. 과정의 마지막 오답 재시험은 별도 10단어 복습 테스트와 다르며, 그 재시험 문항은 복습 최대 XP 계산에 더하지 않습니다.

## 오답노트와 오답 퀴즈

**오늘 → 오답 다시 도전** 또는 **복습함 → 오답노트 보기**를 누릅니다. 회차를 끝내기 전에도 저장된 오답이 바로 나타납니다. 두 단어장의 단어·문장·독해를 함께 보며 영역 필터와 검색으로 찾을 수 있습니다. 단어는 같은 어휘끼리 묶고 문장·독해는 문제별로 구분합니다.

최근 오답 뒤 **서로 다른 퀴즈에서 두 번 정답**을 저장하면 목록에서 해제됩니다. 새로 틀리면 `0 / 2회`로 돌아갑니다. 같은 퀴즈에서 여러 번 맞혀도 한 번만 세며, 회차 마지막 재시험이나 힌트 정답도 한 번의 기여가 가능합니다. 이 횟수는 숙련도와 별도이며, 목록에서 사라져도 학습 기록은 지우지 않습니다.

**오답 퀴즈 시작**은 최근 오답부터 최대 10개를 고릅니다. 하나만 있어도 풀 수 있고, 현재 단어장이나 화면 필터에 관계없이 전체 미해결 항목을 대상으로 합니다. 중단했다면 **오답 퀴즈 이어하기**로 같은 문항부터 계속합니다. 한 문항을 제출한 뒤 해설을 확인하고 다음으로 넘어가며 즉시 재도전은 없습니다.

전용 오답 퀴즈는 **추가 XP와 하루 완료 보너스를 지급하지 않습니다**. 별도 10단어 복습 테스트와 기존 과정 재시험의 보상은 그대로입니다. 다른 퀴즈에서 오답을 해제해도 이미 정한 회차의 마지막 재시험 문항은 그대로 남습니다.

## 단어와 뜻 찾아보기

**오늘 또는 복습함 → 단어장 둘러보기**에서 두 권의 목록을 엽니다. **단어 또는 뜻 검색**, **더 보기**, 수능 책의 **원문 DAY**를 사용할 수 있습니다.

목록의 **중복 단어 제외**는 처음에 켜져 있습니다. 수능 새 단어 1,824개를 보여 주며, 끄면 다른 책과 겹치는 176개도 포함한 2,000개를 봅니다. 이 목록 필터는 학습 과정의 100회차 분량을 줄이지 않습니다.

`provide`와 `제공하다` 모두 검색할 수 있습니다. **뜻 출처**에는 사전 원전과 이용 조건·정리 방법이 있습니다. 원문 PDF의 뜻 칸은 비어 있었으며 별도 자료로 한국어 뜻을 보강했습니다. 원문 `vaccum`·`lagacy`는 보존하고 `vacuum`·`legacy`로도 찾을 수 있습니다. 학습 과정에서는 확인한 철자를 사용합니다. 용법 주의가 필요한 단어는 해당 안내를 함께 읽어 주세요.

검색과 읽기만으로 XP·숙련·회차 진도가 바뀌지는 않습니다. 사전 뜻은 기기에 포함되어 오프라인으로 읽으며, 외부 출처 웹페이지를 직접 열 때만 인터넷이 필요합니다.

## 친구·성장 기록·백업

설정에서 몬치치·시치와레·시폼푸린을 선택합니다. 이전 모모는 시치와레, 노바는 시폼푸린으로 표시되며 선택은 백업에도 남습니다. **성장 기록**은 현재 책의 완료 회차와 전체 탐험 이력·XP를 함께 보여 줍니다. 높은 XP만으로 영어 숙련이나 수능 성적을 판단하지 않습니다.

Android의 **백업 파일 저장**, 웹의 **백업 다운로드**로 JSON을 보관합니다. **백업 파일 선택 → 백업으로 복원**은 현재 기록을 파일 내용으로 교체하므로 복원 전 현재 기록도 백업하세요. 자동 합치기는 하지 않습니다.

현재 백업은 스키마 6이며 이전 스키마 1·2·3·4·5도 읽습니다. 이전 49단계 회차는 원래 위치와 순서로 계속 진행하고, 새로 시작하는 회차부터 문제 중심 흐름을 적용합니다. 구매 내역과 장착 상태도 함께 보관합니다. 예전 데모 파일도 원본 그대로 가져올 수 있고, 검증 뒤 현재 앱 저장소에 맞춰 내부 모드 정보만 옮깁니다. 답변·SRS·XP·ID는 유지합니다. 파일 내용을 임의로 바꿔 모드를 위장하지 마세요.

Android 업데이트는 **기존 앱을 삭제하지 않고 같은 앱 ID·서명의 0.12.0 APK를 설치**합니다. 앱 삭제·데이터 지우기는 업데이트 방법이 아닙니다. iPhone PWA는 같은 주소(origin)의 기존 홈 화면 앱을 업데이트하며, 기록을 옮기려고 앱이나 Safari 데이터를 삭제하지 않습니다. 다른 주소·기기로의 자동 동기화는 없으므로 JSON 백업으로 옮깁니다. 기기 저장소 정리 등에 대비해 백업을 따로 보관하세요.

[Android 설치 안내](ANDROID_INSTALL.md)와 [현재 변경·검증 보고서](MISTAKES_REPORT.md)를 참고하세요. 실제 Android 휴대폰과 iPhone 검증은 아직 수행하지 않았습니다.
