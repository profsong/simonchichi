## 0. 2026-11-01 명시적 사용자 변경 요구

이 절과 갱신된 본문이 예전의 승인 전 차단·12분/5단어 계획·독해 단계 선택보다 우선합니다. 원본의 `reviewStatus`를 거짓으로 `approved`로 바꾸거나 교사 검수 완료를 주장하지 않고, 사용자가 적재된 자료의 사용을 허용한 사실을 실행 정책에 반영합니다.

- 화면에는 **중등 심화 300(`advanced-300`)**와 **수능 영어 2000(`suneung-2000`)** 두 권만 제공합니다. 기존 B1·B2·B3는 첫 책 안에 합칩니다.
- 오늘 화면 상단과 설정의 **학습 단어장** 선택을 저장하고, 선택한 책의 다음 회차·진행 중 위치·지도를 보여줍니다. 300단어는 15회차, 2,000단어는 100회차입니다.
- 각 회차에 20단어·구문 2문항·독해 2지문(각 1문항)을 모두 배정합니다. 기존 12분 예산으로 단어를 줄이거나 독해 밴드를 수동 선택하지 않습니다.
- 수능 과정은 기존 책과 겹치는 176개를 포함하여 원문 2,000개 전체를 다룹니다. 같은 공통 어휘의 기억 기록은 공유하되 두 과정의 회차 완료는 별도로 셉니다.
- 복습함은 정사각형 아바타 방 → **10단어 복습 테스트** → 단어장 목록 링크 순서로 제공합니다. 학습한 단어에서 객관식 5개·첫 글자를 제공하는 영문 입력 5개를 구성하고, 이전 오답 단어의 추출 확률을 높입니다. 첫 글자 도움을 받은 답은 무힌트 회상 숙련으로 세지 않습니다.
- 콘텐츠 준비 안내·검수 모드 토글·독해 단계 선택을 제거합니다. 원문·사전 출처·사용상 주의·정답 근거는 유지합니다.
- 기존 60개 계획, 학습 기록, XP, 백업은 보존합니다. 새 15/100회차는 별도 안정적 ID를 사용하며 과거 완료를 새 회차 완료로 자동 변환하지 않습니다.
- 백업 스키마 6을 내보내며 이전 1·2·3·4·5도 지원합니다. 정상적인 이전 데모 백업은 원래 모드로 검증한 뒤 현재 저장소로 명시적으로 옮깁니다. 원본 파일은 바꾸지 않고 내부 모드 정보 외 답변·보상·SRS·ID를 보존합니다.
- 배경·옷·액세서리를 XP로 구매하고 장착합니다. 누적 획득 XP는 보존하며 사용 가능 잔액은 구매 지출을 뺀 값입니다. 소유한 아이템의 재장착과 무료 기본 아이템은 재차 결제하지 않습니다.
- 유료 배경은 모두 **12,000 XP**, 일반 옷은 **6,000 XP**, 액세서리는 **2,500 XP**입니다. 새 프리미엄 옷 3종(나이키 후드티·아디다스 패딩·버버리 코트)은 각각 **7,000 XP**이며 기존 상품의 가격은 바꾸지 않습니다. 하루 새 회차 3~4개에서 새 문항 24개×10 XP와 하루 보너스 30 XP를 얻는 750~990 XP(중간 870 XP) 기준으로 배경·일반 옷·액세서리는 약 14일·7일·3일을 목표로 합니다. 기억 채우기의 반복 보상과 별도 무제한 복습은 이 추정에서 제외하며 정답률에 따라 달라집니다. 시간 잠금이나 확정 소요기간이 아닙니다. 기존 구매 금액·소유권·잔액은 재계산하지 않고 새 구매에만 가격 버전 2를 기록합니다.
- 배경은 총 14개이며 미구매 상태에는 이름·설명·가격·구매 버튼만 표시합니다. 이미지·장면·미리보기 DOM은 구매 결과가 저장된 뒤 만들며, 보유 배경은 장착 여부와 관계없이 모두 미리보기를 유지합니다. 무료 기본 배경과 옷·액세서리의 미리보기는 그대로 제공합니다.
- 액세서리는 무료 ‘액세서리 없이’를 포함해 14종으로 확장합니다. 새 10종은 세 친구의 전체 모습과 프로필에 적용하는 로컬 SVG이며 구매 전에도 미리보기를 보여 줍니다. 한 번에 하나를 장착하고 소유품 재장착은 무료입니다. 배경 14·옷 14·액세서리 14, 전체 42개(무료 3·유료 39)이며 유료 액세서리 2,500 XP·가격 버전 2·백업 6·기존 영수증은 유지합니다.
- 옷은 기존 4종에 새 10종을 더해 무료 원래 옷 포함 14종입니다. 새 일반 옷 7종은 민트 가디건·데님 재킷·스트라이프 니트·라벤더 맨투맨·레몬 레인코트·크림 플리스·리본 원피스입니다. 위 프리미엄 3종과 모두 세 친구에 적용하며 구매 전 미리보기·한 번에 옷 하나 장착·소유품 무료 재장착을 유지합니다.
- 새 복습 테스트는 시작 시 오늘 선택한 과정의 기본 획득 가능 XP를 고정합니다. 최대 보상은 그 값의 30%를 내림한 값이고, 실제 보상은 최대 보상×첫 응답 정답 수/10을 다시 내림합니다. 완료 시 한 번 지급하며 하루 횟수 제한 없이 새 테스트마다 받을 수 있습니다. 이전 정책의 세션은 원래 계산을 보존합니다.
- 새 회차의 단어 20개는 영어를 보고 한국어 뜻을 고르는 문제로 바로 시작하며, 별도 뜻 카드 20개를 제거합니다. 독해가 끝나면 처음 틀린 단어만 원래 순서로 한 번 다시 풀고, 다른 영역 오답과 재시험 오답은 추가하지 않습니다. 이전 49단계 진행 기록은 그대로 이어갑니다.
- 실제 iPhone·Android 휴대폰 검증 여부는 자동 브라우저·에뮬레이터 결과와 계속 구분합니다.

## 1. 문제 정의와 제품 목표

### 1.1 해결할 문제

1. 중학교 상위권 학생은 기초 단어 암기 앱에 금방 싫증을 낼 수 있다.
2. 기존 수능 앱은 고등학생을 전제해 지나치게 어려운 지문, 진도 중심 학습, 대량 문제풀이에 편중될 수 있다.
3. 4지선다를 반복해 높은 정답률이 나와도 문장에서 단어를 직접 떠올리고 해석하는 능력으로 이어지지 않을 수 있다.
4. 퀴즈를 오래 해도 어떤 단어와 구문을 다시 학습해야 하는지 체계적으로 결정하지 못한다.
5. 가족 전용 앱에는 가입·결제·광고·랭킹·복잡한 서버 운영이 필요하지 않다.

### 1.2 제품 목표 / 비목표

**목표**

- 단어장별 20단어·구문 2개·독해 2개의 회차를 학습자가 원하는 때에 중단·재개할 수 있게 제공.
- 진단 학습을 통해 중2 심화~고등 영어 기초 사이의 적절한 시작 난도 결정.
- 기존 300단어와 출처를 보강한 수능 2,000단어를 각각 15/100회차의 독립 학습 동선으로 제공.
- 문맥형 정답과 능동 회상 정답을 구분하여 숙련도를 추적.
- 7일 지연 회상 평가와 실제 학습 이력을 사용한 진도 피드백.
- iPhone에서 홈 화면 설치, 오프라인 실행, 데이터 백업 가능.

**비목표(MVP에서 제외)**

- 수능 기출문제의 대량 복제·자동 크롤링, 유료 교재의 무단 재배포.
- LLM을 이용한 실시간 무제한 대화, 음성 인식 채점, 멀티플레이 경쟁.
- 결제·광고·소셜 피드·외부 랭킹.
- 완전한 공인 영어 능력 등급(CEFR/수능 등급) 판정.
- 부모용 과도한 감시 기능.

### 1.3 주요 성공 지표 — 목표치이지 예측치가 아님

- 채택: 첫 14일 중 자발적으로 8일 이상 학습 완료 (초기 가설).
- 사용성: 실제 회차 소요시간을 관찰하되 고정 시간 안의 완료를 강요하지 않으며, 중단·재개가 쉽고 압박감이 없을 것.
- 학습: 7일 후 능동 회상 문제 정답률(기준선과 비교), 문장형 문제 정답률.
- 제품 품질: 출제된 모든 문제의 정답이 하나이며, 복습 기록 손실이 없고, 오프라인 퀘스트 수행 가능.
- 평가 접근: '매일 출석 횟수'만으로 학습 성과를 판단하지 않는다.

## 2. 교육과정 대응과 난이도 체계

2026학년도 중2에는 2022 개정 교육과정이 적용된다. 공식 영어과 성취수준 자료와 연계해 '이해하기·표현하기, 읽기와 실제 의사소통'을 고려하되, 아래 내부 레벨은 **앱 자체의 설계 분류**이며 교육부가 고시한 공식 등급이 아니다.

| 내부 단계 | 설명                 | 어휘 목표                     | 짧은 독해 예시 | 진입 기준                  |
| --------- | -------------------- | ----------------------------- | -------------- | -------------------------- |
| B0        | 중2 상위권 기초 점검 | 중학교 핵심어·빈출 어법       | 90~140단어     | 진단에서 약점 확인         |
| B1        | 중등 심화            | 추상적 의미, 주요 구동사·연어 | 120~180단어    | 문맥과 구문 정확도 확인    |
| B2        | 중3~고1 연결         | 다의어, 복합 문장·논리 연결   | 160~230단어    | 문장 추론과 능동 회상 가능 |
| B3        | 고등 영어 기본       | 학술적 빈출어·문장 변환       | 200~300단어    | 고등 연결 단계 안정화      |
| B4        | 수능 독해 입문       | 요지·추론·빈칸·배열           | 230~350단어    | 장문 부담·오답 원인 확인   |

- 단어 수·읽기 길이는 난이도 설계 가이드이며, 공식 평가 규격이 아니다.
- 한 가지 점수로 레벨을 단정하지 않는다. 어휘·구문·독해의 세 영역별 시작 레벨을 별도로 관리한다.
- 현재 화면에서는 읽기 레벨 수동 선택을 제공하지 않습니다. 선택한 단어장의 회차에 배정된 구문·독해를 사용합니다.
- 특정 시기에 수능을 볼 학생이라는 이유로 현재 시험 시간 제한을 강요하지 않는다.

### 2.1 후속 범위: 최초 진단(총 30문항)

| 영역             | 문항 수 | 목적                              |
| ---------------- | ------: | --------------------------------- |
| 어휘 의미·다의어 |      12 | 중등 심화~고등 기본 어휘의 이해   |
| 문맥 속 사용     |       6 | 어휘의 맥락 적용 및 표현 비교     |
| 구문/문장 구조   |       6 | 수식 범위, 절 관계, 논리 연결     |
| 짧은 독해        |       6 | 세 지문 × 두 문항: 요지·세부·추론 |

- 난도별 문항을 섞되 무작위 추측으로 선발되지 않도록 영역별 정답과 응답 시간을 함께 본다.
- 초기 레벨은 앱이 *추천*하며 학습자가 수정할 수 있다. 30문항으로 CEFR/수능 등급을 예측한다고 주장하지 않는다.
- 진단 점수는 학습 게임 점수와 분리; 틀린 답도 솔직하게 고를 수 있도록 유도한다.
- 진단용 문항은 일반 훈련용 문항과 겹치지 않게 관리한다.

### 2.2 현재 단어장별 과정

| 과정 ID        | 구성                        | 회차 수 | 회차당 단어 | 구문/독해                     |
| -------------- | --------------------------- | ------: | ----------: | ----------------------------- |
| `advanced-300` | 기존 B1 80 + B2 140 + B3 80 |      15 |          20 | 구문 2문항 + 독해 2지문/2문항 |
| `suneung-2000` | 원문 순서의 전체 2,000단어  |     100 |          20 | 구문 2문항 + 독해 2지문/2문항 |

과정 진도는 책별로 독립적입니다. 수능 단어장의 원문 DAY 하나는 40단어이므로 새 과정의 두 회차에 해당합니다. 원문의 철자·행 ID·DAY·페이지는 보존합니다. 176개 중복 단어는 공통 어휘 ID로 연결하지만 수능 과정의 전체 분량에서 빼지 않습니다.

이전 12주·60일 계획은 과거 기록과 백업의 해석을 위해 보존합니다. 그 300단어의 이전 배정은 [과거 12챕터 문서](CURRICULUM_MAP.md)에 남기며, 현재 15회차와 동일한 완료 기록으로 간주하지 않습니다.

### 2.3 현재 회차와 별도 복습

1. **기억 채우기 5개**: 학습한 단어를 복습합니다. 배운 단어를 최대 5개 복습하고 부족한 수만큼 이번 회차 단어의 미리보기 카드로 채웁니다.
2. **단어 테스트 20개**: 영어 단어를 보고 한국어 뜻 네 개 중 하나를 고릅니다. 앞선 별도 뜻 카드는 없습니다.
3. **문장 해독**: 구문 문제 2개를 풉니다.
4. **독해**: 짧은 지문 2개를 읽고 각 1문항을 풉니다. 제출 뒤 실제 원문 근거를 확인합니다.
5. **오답 다시 도전**: 첫 단어 테스트에서 틀린 단어만 한 번 다시 풉니다.
6. **마무리**: 재시험까지 끝낸 기록을 보관하고 쉬거나 다음 회차를 선택합니다. 중간에도 저장하고 나갈 수 있습니다.

복습함에서는 학습한 단어만 사용하는 10문항 테스트를 따로 시작·재개합니다. 객관식 5개와 첫 글자가 표시되는 입력형 5개로 구성하고, 오답 이력이 있는 단어를 더 자주 뽑습니다. 무한 자동 재시작이나 제한시간은 두지 않습니다.

기본은 29단계이며 배운 단어가 없는 첫 학습은 기억 채우기 미리보기 카드 5개와 답변 문항 24개입니다. 기억 채우기의 복습 문제 수에 따라 기본 답변은 24~29개입니다. 독해 뒤 처음 틀린 단어 0~20개를 한 번 다시 풀어 전체는 29~49단계가 됩니다. 재시험에서도 틀리면 해설을 확인하고 마치며 다시 반복하지 않습니다. 이 분량을 12분에 마칠 수 있다고 약속하지 않습니다. 실제 학습 속도에 맞게 멈췄다가 이어 하며, 오래 걸리거나 하루 쉬어도 불이익이 없습니다.

## 3. 게임 디자인: 학습을 해치지 않는 재미

### 3.1 세계관/화면

- 제목: **시몬치치** / 부제: "Unlock your next level".
- 세계는 네 지역으로 구분: Word Forest(어휘) → Syntax Lab(문장) → Reading City(독해) → Exam Island(수능 입문).
- 각 지역에 작은 퀘스트, 레벨이 아닌 **숙련 배지**를 부여.
- 앱 테마 선택: 과학, 동물, 음악, 스포츠, 여행 등. 향후 사용자의 선호 주제로 자체 제작 지문을 구성.
- 아바타 방의 배경·옷·액세서리는 학습으로 얻은 XP로 구매합니다. 무료 기본 아이템과 고정 가격 상품을 제공하고 소유한 상품은 무료로 다시 장착합니다. 실제 돈 결제·확률형 상품은 없습니다.

### 3.2 게임 이벤트와 보상 규칙

| 이벤트                          | 보상                      | 설계 원칙                             |
| ------------------------------- | ------------------------- | ------------------------------------- |
| 첫 시도에서 정답                | +10 XP                    | 한 학습 문항의 첫 응답에 한 번만 지급 |
| 오답 후 해설 확인과 재도전 성공 | +3 XP                     | 반복 클릭으로 점수 무한 획득 금지     |
| 하루 퀘스트 완료                | +30 XP                    | 하루 1회, 보너스는 학습량과 균형      |
| 7일 간격의 지연 회상 성공       | 복습 배지 1단계           | 실제 기억 증거를 인정                 |
| 주간 보스전                     | 지역 진행도/아바타 아이템 | 틀려도 재도전 가능                    |
| 쉬는 날                         | 감점 없음                 | 연속 출석 강제·불안 유발 방지         |

- 새 10단어 복습은 완료 시 첫 정답 비율에 따른 별도 보상을 지급하며 문항별 +10/+3 보상을 함께 주지 않습니다. 270 XP 회차가 기준이면 최대 81 XP, 320 XP 회차가 기준이면 최대 96 XP입니다. 예를 들어 81 XP 기준 첫 정답 9개는 72 XP입니다.
- 총 획득량은 성장 기록에 유지하고 상단 XP는 구매 후 사용 가능한 잔액을 표시합니다. 결제·소유·장착은 한 저장 트랜잭션으로 처리하며 잔액 부족과 중복 영수증을 거절합니다.
- '힌트 사용'은 학습에는 유용하지만 독립적인 능동 회상 성공으로 계산하지 않는다.
- 레벨 상승은 XP와 학습 숙련도를 분리한다. XP가 높은 것만으로 어려운 지문을 강제로 해금하지 않는다.
- 정확한 정답보다 빨리 누른 것을 더 높이 평가하지 않는다. 제한시간 모드는 선택 사항으로 제공.
- 문제당 즉각 피드백: 맞혔는지, 왜 맞았는지, 왜 오답이 오답인지. 부정적 표현·수치심 유발 연출 금지.
- 주간 보스전도 이미 배운 내용을 중심으로 구성하며 학습 결과에 따라 난도 조정.

### 3.3 퀴즈 유형

| 유형 ID              | 학생의 행동                            | 숙련도 판정 기여도  |
| -------------------- | -------------------------------------- | ------------------- |
| `recognition`        | 영어 → 한국어 의미 4지선다             | 낮음 (인식 능력)    |
| `meaning_in_context` | 예문 속 해당 단어 의미 선택            | 중간                |
| `recall`             | 한국어 힌트 → 영어 단어 직접 입력      | 높음 (능동 회상)    |
| `cloze`              | 문장 빈칸의 적절한 단어 직접 입력/선택 | 높음 (문맥 적용)    |
| `collocation`        | 자연스러운 연어 짝짓기                 | 중간                |
| `syntax`             | 복잡한 구문의 수식 관계/논리 표시      | 별도 구문 영역      |
| `paraphrase`         | 같은 의미의 다른 영어 문장 선택        | 별도 구문/독해 영역 |
| `reading`            | 요지/세부/추론/삽입                    | 별도 독해 영역      |

- 모바일 입력형에서는 대소문자·앞뒤 공백을 허용하고 오탈자 관용 정책을 문항 단위로 정의. 무분별한 fuzzy-match는 유사하지만 뜻이 다른 단어를 정답 처리할 위험이 있어 기본 제외.
- 복수 정답이 가능한 문항은 애초에 출제하지 않거나 `acceptedAnswers[]`를 명시한다.
- `reading`에는 반드시 본문 근거와 해설을 수록한다.

## 4. 개인화 알고리즘

### 4.1 기억 복습: 설명 가능한 SM-2-lite 초기 버전

FSRS 등의 고급 간격 반복 알고리즘은 로그가 쌓인 뒤 도입할 수 있다. MVP는 시간대 문제와 테스트가 쉬운 **명시적 간격 규칙**으로 시작한다.

```text
stage = 0 (미학습), 1~5 (복습 진척)
intervalDays = {1:1, 2:3, 3:7, 4:14, 5:30}

처음 학습 완료 / 첫 정답:
  stage = max(1, stage)
  dueDate = 내일

독립적 회상 성공 (힌트 없이 정답):
  stage = min(5, stage+1)
  dueDate = 오늘 + intervalDays[stage]

오답 또는 힌트 후 정답:
  stage = max(0, stage-1)
  다시 학습할 대상으로 지정
  오늘 세션의 마지막에 한 번 재도전(가능하면)
  다음날까지 1회 재복습 예약

문항 숙련(mastery) 인정:
  서로 다른 날의 독립 정답 >= 3회
  그중 recall 또는 cloze 성공 >= 2회
  의미를 문맥에 적용한 성공 >= 1회
  마지막 연속 성공 간격 >= 7일 한 번 경험
```

**구현 주의:** 위 규칙은 알고리즘 사양이지 학습 효과를 보장하는 최적 간격이 아니다. 단어의 뜻(sense)을 구분하여 기록한다. 인식 문제만 반복 정답이면 능동 회상 숙련으로 인정하지 않는다. 임의 날짜의 재학습에서도 `dueDate`가 역전되지 않아야 한다.

### 4.2 회차 선택과 복습 추출

- 선택한 단어장의 진행 중 회차를 먼저 재개하고, 없으면 다음 미완료 회차를 시작합니다.
- 회차의 20단어·구문 2개·독해 2개를 유지합니다. 과거 시간 예산에 맞춰 일부 단어를 생략하지 않습니다.
- 복습 테스트는 실제 학습한 공통 어휘만 대상으로 합니다. 새 단어를 미리 복습 문제로 노출하지 않습니다.
- 객관식 5개·첫 글자 입력 5개를 무작위로 구성하되, 이전 오답의 추출 가중치를 높입니다. 가중치와 중복·적은 후보 처리 규칙은 순수 함수와 테스트로 검증합니다.
- 선택된 세션은 저장하여 새로고침이나 빠른 재시작으로 문제·보상이 바뀌지 않게 합니다.
- 첫 글자 도움은 회상 지원으로 기록하며 무힌트 능동 회상 숙련을 부풀리지 않습니다.

### 4.3 후속 범위: 적응적 난이도

- `vocab`, `syntax`, `reading` 영역별 최근 20개의 첫 시도 성공률, 오답 유형, 중간 응답 시간을 기록.
- 두 번 이상의 서로 다른 날에 상위 문항에서도 높은 이해도가 확인되면 다음 밴드의 일부를 섞는다.
- 연속 오답이 계속되면 짧은 지문·기존에 배운 단어 비중을 높인다. 학습자에게 '레벨 강등'이라고 표현하지 않는다.
- 빈칸 추론 문제에 약하더라도 어휘 레벨을 모두 떨어뜨리지 않는다.
- 초반에는 규칙 기반으로 충분하며 RL/MARL, 거대 추천 모델 도입은 불필요하다.

### 4.4 학습 지표

- `reviewRetention7d`: 학습 후 6~9일 경과한 아이템의 힌트 없는 첫 응답 회상 정확도.
- `activeRecallRate`: `recall`/`cloze` 문항 중 힌트 없이 맞힌 비율.
- `readingEvidenceRate`: 읽기 문제의 근거 문장을 정확히 찾아낸 비율(근거 표시 기능이 있을 때).
- `timeOnTask`: 권장 시간 지표일 뿐, 길어졌다고 패널티 없음.
- `practiceDays`: 게임 참여 현황; 교육 효과 지표와 분리.

## 5. 콘텐츠 제작 규격과 검수

**현재 정책:** 사용자는 적재된 두 단어장을 정상 사용하도록 명시적으로 허용했습니다. 원문 검수 상태와 출처는 보존하며 교사 검수 완료를 주장하지 않습니다. 2026-10-23의 초안 콘텐츠와 이전 커리큘럼 데이터도 이력 호환을 위해 그대로 보관합니다. 실제 휴대폰 검증 여부는 구현 보고서에 별도로 기록합니다.

### 5.1 현재 과정과 보존 원본

현재 과정은 중등15회·수능100회, 구문230문항·독해230지문/230문항입니다. 독해는 기존 원작30개를 검토하여 새과정 복사본으로 연결하고 수능200개를 새로 집필했습니다. 각 회차20단어를 사용하며, 아래 원본 문제은행은 이력 호환을 위해 별도로 보존합니다.

1. 정식 커리큘럼: **독립 검수 후 승인된 단어 300개** 목표(중등 심화 80, 중등→고등 연결 140, 고등 영어 기본 80). 현재 패키지에는 300개 **초안(draft)** 이 제공된다. 방대한 수능 3,000개보다 질을 우선한다.
2. 독해: **자체 창작 짧은 지문 60개** 목표(12주 × 주 5개). 각 지문 2개 문제와 정답 근거, 한국어 해설.
3. 구문: **자체 제작 문제 60개** 목표(주 5개). 비슷한 오답을 설계하되 정답 중복 금지.
4. 별도 진단용 30문항; 주간 보스전은 이미 학습한 소재를 변형해 출제.
5. 패키지의 `src/data/seed-content.json`에는 300개 단어, 단어 객관식 600문항, 구문 60문항, 독해 60지문/120문항, 진단 30문항, 12주 일정이 수록되어 있다. **모든 콘텐츠는 미검수 `draft`** 이며 공식 검수 완료 문제은행이 아니다. 원래 60개 시범 데이터는 `src/data/seed-content.demo-original.json`에 보존했다.

### 5.2 문제은행 필수 메타데이터

- 공통: `id`, `type`, `level`, `tags[]`, `estimatedSeconds`, `license`, `reviewStatus`, `version`.
- 단어: `headword`, `partOfSpeech`, `koreanMeaning`, `englishDefinition`, `exampleEn`, `exampleKo`, `collocations`, `acceptedAnswers`, `distractors`.
- 독해: `passageEn`, `wordCount`, `questions[]`(`promptKo`, `choices[]`, `correctIndex`, `explanationKo`, `evidenceQuote`).
- 구문: `sentenceEn`, `promptKo`, `choices[]`, `correctIndex`, `explanationKo`, `focus`.
- `reviewStatus`는 원자료의 검수 이력으로 보존합니다. 현재 사용자가 받아들인 단어장·과정은 일반 실행에서 사용할 수 있으며 과거 승인 전 차단 화면은 두지 않습니다.

### 5.3 자동 검수 + 사람 검수

- JSON Schema/Zod으로 필수 필드 검사; ID 유일성, 최소 문항 수, 선택지 중복, 정답 인덱스 범위 검사.
- 독해 `evidenceQuote`는 `passageEn`에 실제로 포함되어야 한다.
- 지문 `wordCount`를 빌드시 재계산해 저장값과 일치 확인.
- 동일 의미의 선택지(예: 예상하다 vs 예측하다)가 다른 보기로 들어가면 콘텐츠 검수에서 거부.
- 정답성·영어 자연스러움·한국어 번역은 저작자 검토와 원전 대조를 수행합니다. 새 과정의 실행 허용 상태는 사용자 수용 정책을 나타냅니다. 독립적인 교사 검수는 별도 이력으로 기록하고 기계 검사와 혼동하지 않습니다.
- 저작권 원칙: 수능/EBS/유료 단어장 본문이나 해설을 무단 복제하지 않는다. 자체 창작 예제나 명확한 재사용 권한이 있는 자료만 수록; 출처와 이용 허락 조건 보관.
- 새로운 자료의 출처·정답·근거 검증과 독립 교육 검수 이력은 별도로 관리합니다. 자동 검사를 통과했다는 이유만으로 교사 승인 상태를 기록하지 않습니다. 현재 적재 과정의 사용 허용은 사용자 지시에 따른 실행 정책입니다.

## 6. IA(정보 구조)와 상세 화면 명세

### 6.1 탭 및 화면

```
온보딩 / 최초 진단 (처음 1회)
  └─ 홈 (Today)
       ├─ 회차 학습 (Vocabulary 20 → Syntax 2 → Reading 2)
       ├─ 모험 지도 (선택한 단어장 15/100회차)
       ├─ 복습함 (단어장 목록 + 배운 단어 10문항 테스트)
       ├─ 성장 기록 (능동 회상률, 구문, 독해 추이, XP)
       └─ 설정 (학습 단어장, 테마, 소리, 백업/복원)
```

### 6.2 홈

- 상단 학습 단어장 선택, 해당 과정의 회차·진행률, 시작/이어서 하기의 대표 행동.
- 지난 학습에서 틀린 어휘 2개만 노출(부끄러움을 주는 표현 금지).
- 일일 목표를 완료했으면 '오늘은 충분히 했어요'와 선택형 복습 버튼 제공.
- 세로 모바일 360~430 CSS px 우선. 하단 safe area 고려.

### 6.3 문제 화면

- 상단: 퀘스트 단계, 남은 문항, 나가기/일시정지.
- 본문: 단어/예문/지문; 읽기 화면에서는 문제를 풀면서 지문을 위로 스크롤 가능.
- 답 입력: 4지선다 또는 키보드. 답 제출 전 선택 변경 가능.
- 제출 후 정답·오답 색상만으로 구분하지 않고 명시적인 텍스트와 근거 제시.
- '왜 틀렸지?' → 2~4문장 한국어 해설 + 올바른 영어 예문 + 필요 시 수식 관계.
- TTS: 영어 단어·짧은 문장 듣기 버튼. 브라우저 기기 지원 시 사용, 실패하면 조용히 텍스트 대체.
- 접근성: 최소 44×44 CSS px 탭 목표, VoiceOver 대응, 색상 대비·폰트 확대·감소된 모션 선호 반영.

### 6.4 학습 결과 및 보호자 화면

- 학생: 새로 익힌 내용, 다음 복습일, 지문 이해도, 경험치 제공.
- 보호자용 요약: 학습 일수, 복습 필요 어휘 수, 지연 회상 정확도와 개선 추이 **집계만** 보여줌.
- 단일 기기 오프라인 MVP에서 보호자 PIN은 UI 구분용이며 실제 강력한 인증이 아님을 문서화.
- 학습자의 이름·학교·전화번호·친구 정보·위치를 수집하지 않음.

## 7. 기술 아키텍처

### 7.1 단계별 기술 결정

| 영역    | MVP 선택                                    | 이유 / 확장                               |
| ------- | ------------------------------------------- | ----------------------------------------- |
| UI      | React + TypeScript + Vite                   | 단순, 빠르고 Codex가 구현·테스트하기 쉬움 |
| Styling | Tailwind CSS + 자체 디자인 토큰             | 모바일 화면 일관성                        |
| PWA     | `vite-plugin-pwa`                           | 아이콘·manifest·service worker 빌드 지원  |
| 로컬 DB | IndexedDB + Dexie                           | Safari에서 학습 기록 로컬 보존            |
| 검증    | Zod + TypeScript 타입                       | 잘못된 JSON 문제은행 차단                 |
| 상태    | React state / 작은 custom hooks             | MVP에서 Redux 불필요                      |
| 테스트  | Vitest + React Testing Library + Playwright | 알고리즘·UI·E2E 검증                      |
| 배포    | Cloudflare Pages 등 정적 HTTPS 호스팅       | 서버 없이 아이폰에서 접근                 |
| 음성    | Web Speech `speechSynthesis` 선택 제공      | 미지원·오프라인 품질의 편차 고려          |
| AI      | **MVP 비활성화**                            | 이후 서버 측 API proxy 추가               |
| 동기화  | MVP 없음; JSON 백업/복원                    | 기기 변경·데이터 손실 위험 완화           |

**초기 실행 경로**: HTTPS 정적 호스팅에서 앱과 사용자가 허용한 콘텐츠를 받아온 뒤 service worker에 캐시 → iPhone 홈 화면에서 실행 → 학습/복습 데이터는 IndexedDB에 저장 → JSON 백업 다운로드.

**중요한 한계**: 브라우저 데이터 삭제, iOS 저장공간 정책, 기기 초기화 시 로컬 데이터가 사라질 수 있다. '백업 없이 영구 보존'을 약속하지 않는다. 첫 1회 설치/콘텐츠 적재에는 네트워크가 필요하다.

### 7.2 저장 모델(권장 Dexie tables)

```ts
type LearningBand = 'B0' | 'B1' | 'B2' | 'B3' | 'B4';
type QuestionMode =
  | 'recognition'
  | 'meaning_in_context'
  | 'recall'
  | 'cloze'
  | 'collocation'
  | 'syntax'
  | 'paraphrase'
  | 'reading';

type PracticeAttempt = {
  attemptId: string; // UUID
  entityId: string; // vocab sense, syntax or reading-question ID
  entityType: 'vocab' | 'syntax' | 'reading';
  mode: QuestionMode;
  answer: string;
  isCorrect: boolean;
  usedHint: boolean;
  firstTry: boolean;
  responseMs: number;
  completedAt: string; // ISO datetime
  localDay: string; // YYYY-MM-DD on device
  sessionId: string;
};

type ReviewState = {
  entityId: string;
  stage: number; // 0..5
  dueDay: string; // local YYYY-MM-DD
  correctDays: string[];
  activeRecallCorrectDays: string[];
  inContextCorrectDays: string[];
  lastAttemptAt?: string;
  mastered: boolean;
};

type LearningSession = {
  sessionId: string;
  localDay: string;
  phase: 'review' | 'vocab' | 'syntax' | 'reading' | 'complete';
  currentQuestionIndex: number;
  questionIds: string[];
  xpAwarded: number;
  status: 'in_progress' | 'completed' | 'abandoned';
  updatedAt: string;
};
```

- `questionId`와 어휘의 `senseId`는 서로 다름: 한 단어의 여러 뜻을 개별 암기 대상으로 관리.
- `PracticeAttempt`는 append-only 원장으로 기록; `ReviewState`는 파생 상태로 취급.
- 단일 기기라 해도 보상 중복을 막기 위해 `sessionId + questionId + rewardType` 유일 이벤트 처리.
- `localDay` 계산은 명시적으로 기기 날짜를 사용. 하루 자정 기준 일자 변환 테스트 수행.
- 콘텐츠 버전업 시 기존 `entityId`의 뜻/정답을 바꾸지 않도록 안정적 ID 사용; 변경 시 migration.
- JSON 백업에 데이터베이스 schemaVersion/contentVersion 포함. 복원 시 schema 검사와 트랜잭션 사용.

### 7.4 PWA 설치/호스팅

- `manifest.webmanifest`: `name`, `short_name`, `start_url`, `display: standalone`, icon 192/512, `theme_color`, `background_color`.
- `apple-touch-icon.png`, iOS safe-area viewport, 화면 전환·키보드 자동 확대 방지 검토.
- service worker: 정적 코드와 현재 과정 콘텐츠는 precache. DB 자체를 service worker cache에 저장하지 않는다.
- App shell 및 적재한 문제은행은 오프라인에서 동작하고, 서버 AI 기능만 온라인 필요.
- iPhone에서 Safari → 공유 메뉴 → 홈 화면에 추가. 운영체제 버전에 따라 UI 문구가 다를 수 있다.
- Web Push는 iOS 16.4+의 홈 화면 웹앱에서 지원되지만 별도 푸시 서버·권한 요청이 필요하므로 **MVP 제외**.
- 개인용 정적 사이트를 배포할 경우 원본 코드/콘텐츠의 공개 설정을 점검; 가족만 사용하려면 접근 제어 고려. 기존 실험용 Linux 서버/Cloudflare Tunnel 포트를 무심코 공개하지 않는다.

### 7.5 AI 튜터는 2단계

- 규칙: LLM은 **검수된 정답·근거·해설을 바꾸거나 채점하지 않음**.
- 서버는 `itemId`, `studentQuestion`을 받아 승인된 `explanationKo`와 `evidenceQuote`에 근거해 _설명만_ 생성.
- 사용자 본명·학교·자유로운 개인정보는 모델에 보내지 않음. 필요 최소한의 학습 텍스트만 전달.
- OpenAI API 키 / Ollama 접근 키를 프런트엔드 JavaScript나 정적 JSON에 절대 포함하지 않는다.
- 일일 호출량 상한, 응답 토큰 상한, 사용량 로깅·비용 경보 설정.
- 미성년자 이용을 고려해 개인정보 입력 차단 안내, 부적절한 생성 콘텐츠 필터, 모르는 내용은 정답처럼 지어내지 않기.
- 로컬 Ollama를 활용한다면 인증된 서버 프록시를 거쳐야 하며, 인터넷에서 추측 가능한 주소로 서버를 직접 공개하지 않는다.

## 8. 개발 순서와 작업 단위

### Phase 0 — 프로젝트 부트스트랩

- Vite React TS, Tailwind, PWA, Dexie, Zod, Vitest, Playwright 설치.
- `AGENTS.md`, 문서, eslint/prettier, scripts 구성.
- 모바일 홈 화면(모의 데이터), 퀘스트 UI 컴포넌트 개발.
- 정적 배포와 홈 화면 추가 경로 확인.

**완료 기준:** `npm run dev`, `npm run build`, `npm run test` 통과, iPhone Safari에서 홈 화면 렌더링.

### Phase 1 — 최소 작동 제품 (MVP)

- 300개 어휘와 60개 구문·60개 독해가 수록된 **검수 전 콘텐츠 초안** 및 검증 스크립트. 60개 초기 예제는 별도 파일에 보관.
- 학습/퀴즈/정답 피드백, append-only Attempt 저장.
- 간격 반복 스케줄러와 복습함; 보상 중복 방지.
- 오늘 퀘스트 4단계, 진행 중 새로고침 복구, 오프라인 실행.
- JSON 학습 데이터 백업 및 복원.

**완료 기준:** 학습자가 실제 iPhone에서 회차를 진행·중단·재개하고 별도 복습을 사용할 수 있다. 현재 적재 과정은 일반 실행에서 바로 사용합니다. 실기기 확인을 수행하지 않았다면 자동 테스트 성공과 구분하여 미검증으로 기록합니다.

### Phase 2 — 교육품질과 12주 운영

- 사용자 수용 정책의 두 과정15/100회차를 일반 실행에서 바로 제공합니다. 원본과 새과정의 의미 검토 이력은 보존하며, 독립 전문가 검수는 후속 교육 품질 확인으로 구분합니다.
- 현재 포함된 별도 진단 30문항과 어휘/구문/독해 내부 레벨을 검수하고 앱에 연동하기.
- 현재 정의된 주간 보스전 12회·일일 계획 60일을 앱에 연동하고, 선호 주제·아바타 꾸미기·실제 지연 회상 지표 구현하기.
- 콘텐츠 검수 대시보드 또는 스프레드시트 기반 관리 파이프라인.

### Phase 3 — 선택적 고도화

- 검수된 문제 기반 AI 한국어 해설 및 질문 응답.
- 보호자 리포트, 데이터 동기화(필요하면 서버에 최소 정보만 저장).
- 음성 듣기, 읽기 근거 표시, 개인화 학습 계획 최적화.
- 실제 앱 테스트 결과가 있을 때만 고급 SRS·추천 모델 도입.

## 9. 테스트·수용 기준(DoD)

### 9.1 단위 테스트

1. 동일 콘텐츠 ID의 두 질문도 서로 다른 mode로 구분된다.
2. 4지선다에 정확히 4개의 중복 없는 선택지와 단 하나의 정답이 존재한다.
3. 동일한 답을 재제출해도 XP가 중복 지급되지 않는다.
4. 올바른 무힌트 회상은 다음 복습일을 적절히 늦춘다.
5. 오답/힌트 사용은 mastery에 포함되지 않고 복습이 다시 예약된다.
6. 기기 날짜가 23:59→00:00를 통과해도 due 목록과 하루 보상 계산이 일관된다.
7. 앱을 새로고침하거나 화면을 닫아도 진행 세션의 문항·진도가 복구된다.
8. 서버 오프라인에서도 캐시된 앱과 문제은행이 작동한다.
9. 백업→로컬 데이터 삭제→복원 후 attempts, reviewState, XP, contentVersion이 일치한다.
10. 사용자가 받아들인 두 단어장은 일반 실행에서 즉시 사용할 수 있고, 출처·라이선스·원문 검수 메타데이터를 보존한다. 없는 이용 조건을 임의로 승인하지 않는다.
11. 읽기 정답 근거 문구가 실제 지문에 존재하는지 확인한다.
12. `responseMs`가 비정상적일 때 음수/중대한 이상값을 안전하게 처리한다.
13. 사용자의 회상 답변에서 공백/대소문자 허용 정책이 의도대로 작동한다.

### 9.2 E2E 및 실기기 점검

- 테스트 환경: Chromium 및 Playwright WebKit + **실제 iPhone Safari 및 홈 화면 실행**.
- iPhone 작은/큰 화면, 가로모드, 키보드 오버레이, safe area 점검.
- 인터넷 연결 후 설치 → 비행기 모드 → 다음날 due 퀘스트 테스트(날짜 시뮬레이션 포함).
- 홈화면 진입/학습 완료/다시 진입 후 데이터 유지.
- VoiceOver, 다크 모드, 확대 폰트, reduced motion, 저사양 네트워크 점검.
- TTS 오작동 시 영어 텍스트 학습은 정상 유지.

### 9.3 딸과 진행할 14일 파일럿

- Day 0: 15~20분 진단 후 난도 적절성 확인.
- Day 1~3: 20단어 회차의 실제 소요시간과 중단·재개, 10문항 복습의 조작 불편을 기록.
- Day 4~7: 스스로 앱을 열었는지, 공부 후 이해도가 어떤지 짧은 인터뷰.
- Day 8~14: 복습 완료율·7일 지연 회상률·구문/독해 정답률 확인.
- 비교 기준: 동일한 학습 시간의 기존 앱/일반 교재 대비 *흥미와 지연 회상*을 간단히 비교할 수 있다. 통계적 유의성이나 일반화 효과를 주장하지 않는다.
- 딸이 원치 않는 기능은 제거한다. 가족용 앱이므로 플랫폼의 기능 많음보다 실제 자발적 사용을 우선한다.

| Apple 개발자 계정 | **PWA 가족용 배포에는 불필요**   | App Store 등록으로 전환할 때는 별도 검토 |
| 콘텐츠            | 자체 창작/검수                   | 사실상 가장 큰 품질·시간 비용            |
| 학습 기록         | 단일 기기 IndexedDB              | 데이터 손실 대비 정기 JSON 백업 권장     |

### 10.1 주요 위험

- **학습 효과 위험:** 퀴즈 재미만 높고 회상이 향상되지 않을 수 있음 → 지연 회상 평가 별도.
- **콘텐츠 오류:** 모호한 정답·영어 문법 오류 → 출시 전 사람 검수.
- **운영 위험:** iOS 브라우저 저장소 변경/삭제 → 백업·복원.
- **보안 위험:** API key 노출, 공개된 실험 서버 → 초기에는 서버 없는 구조.
- **동기 위험:** 보호자 의견이 학생의 자발적 재미를 압도 → 테마와 학습량 선택권 제공.
- **스코프 위험:** LLM 챗봇·랭킹·결제·학습 이력 분석을 한꺼번에 구현 → 단순 MVP 고수.
